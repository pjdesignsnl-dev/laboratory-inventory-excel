# Build and test automation

Add repeatable Windows/PowerShell automation here when implementation begins. Candidate responsibilities:

- inspect desktop Excel version;
- export worksheet/Table/name/formula metadata;
- calculate file checksums;
- import/export VBA modules after authorization;
- launch controlled Excel test procedures;
- collect logs and screenshots;
- verify repository/workbook contract consistency.

Never automate enabling unsafe Excel trust settings without explicit owner approval and documentation.
